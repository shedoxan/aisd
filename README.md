# АиСД

Домашние задания по алгоритмам и структурам данных на C++17.

`hw01` - первое ДЗ, `hw02` - второе. Внутри лежат решения по номерам:
`task01.cpp` - первая задача, `task02.cpp` - вторая и так далее.
Каждый файл запускается отдельно. Сначала идёт функция решения, ниже - проверки в `main()`.

## ДЗ 1

1. [Сдвиг массива](hw01/task01.cpp). Нужно перенести последние `k` элементов в начало.
   Сначала разворачиваем весь массив, потом первые `k` элементов и оставшуюся часть.
   `k %= values.size()` убирает полные обороты. Для пустого массива сразу выходим.

2. [Слияние массивов](hw01/task02.cpp). Из двух отсортированных массивов собираем один.
   `i` и `j` показывают, откуда брать следующий элемент. Сравниваем числа и добавляем меньшее.
   Если один массив закончился, дописываем остаток другого.

3. [Слияние без нового массива](hw01/task03.cpp). Результат записываем в первый массив,
   где уже есть свободные места. `i` и `j` считают оставшиеся элементы, `write` - места для записи.
   Берём большее число и ставим справа. Так не затираются ещё не прочитанные числа первого массива.

4. [Сортировка нулей и единиц](hw01/task04.cpp). Собираем нули в начале.
   `i` идёт по массиву, `write` отмечает место следующего нуля. Найденный ноль меняем
   с элементом на `write`, затем двигаем эту границу.

5. [Флаг Нидерландов](hw01/task05.cpp). Сортируем массив из нулей, единиц и двоек.
   `left` отмечает место следующего нуля, `current` - проверяемый элемент,
   `right` - начало готовых двоек. Ноль отправляем влево, двойку вправо, единицу пропускаем.
   После обмена с правой частью `current` не двигаем: пришедшее число ещё нужно проверить.

6. [Чётные вперёд](hw01/task06.cpp). Чётные числа переносим в начало в исходном порядке.
   `write` отмечает место следующего чётного. Просматриваем числа слева направо
   и меняем найденное чётное с элементом на `write`. Порядок нечётных может измениться.

7. [Нули в конец](hw01/task07.cpp). Ненулевые числа собираем слева, сохраняя их порядок.
   `write` отмечает место следующего ненулевого числа. Если `write < i`, число идёт влево,
   а ноль уходит вправо. Если `write == i`, число уже на месте.

## ДЗ 2

1. [Разворот списка](hw02/task01.cpp). `previous` указывает на уже развёрнутую часть,
   `current` - на текущий узел. Сначала сохраняем `current->next`, потом направляем ссылку назад.
   Без сохранения `next` потеряем оставшуюся часть списка. В конце возвращаем `previous`.

2. [Середина списка](hw02/task02.cpp). `slow` идёт на один узел, `fast` - на два.
   Пока быстрый указатель проходит весь список, медленный проходит половину.
   Для чётной длины получается вторая середина: в `[1, 2, 3, 4]` это узел `3`.

3. [Удаление значения из списка](hw02/task03.cpp). Удаляем все узлы со значением `val`,
   как в примере на семинаре. `dummy` стоит перед головой, поэтому первый узел удаляется
   так же, как остальные. `previous->next` перенаправляем в обход удаляемого узла,
   а сам узел освобождаем через `delete`. `previous` при удалении остаётся на месте.

4. [Исходная строка](hw02/task04.cpp). Проверяем, можно ли получить `b` вставками в `a`.
   `i` отмечает следующий нужный символ `a`, `j` идёт по `b`.
   При совпадении двигаем `i`, а `j` двигаем всегда. Если `i` дошёл до конца, все символы найдены.

5. [Пара с нужной суммой](hw02/task05.cpp). В отсортированном массиве берём числа с двух краёв.
   Если сумма мала, увеличиваем левый индекс; если велика, уменьшаем правый.
   Индексы должны различаться. Сумму считаем в `long long`, чтобы не переполнить `int`.

6. [Палиндром](hw02/task06.cpp). Сравниваем первую букву с последней, вторую с предпоследней
   и так далее. `left` и `right` двигаются к середине. При первом несовпадении возвращаем `false`.
   Пробелы и регистр учитываются. В строковых задачах используется `u32string`, чтобы работали
   и русские буквы; строки в примерах записываются как `U"топот"`.

7. [Удаление дубликатов](hw02/task07.cpp). В отсортированном массиве одинаковые числа идут подряд.
   `fast` читает элементы, `slow` отмечает место для следующего нового числа.
   Возвращаем новую длину. Например, после `[1, 1, 2]` значимы только первые два числа `[1, 2]`.

8. [Слияние списков](hw02/task08.cpp). Сравниваем первые оставшиеся узлы двух списков
   и присоединяем меньший к `tail`. `tail` всегда указывает на конец результата.
   Новые узлы не создаём, только меняем ссылки. Если один список закончился,
   присоединяем остаток другого. После слияния удаляем только общий список.

Во всех решениях время линейное: O(n), а для слияний и двух строк - O(n + m).
Дополнительная память O(1), кроме ДЗ 1, задачи 2: там нужен отдельный массив результата.

## Запуск

Пример из папки репозитория:

```powershell
g++ -std=c++17 hw01/task01.cpp -o task01.exe
.\task01.exe
```

Программа напишет `hw01/task01: OK`, если проверки прошли.
`assert` сравнивает результат с ожидаемым и останавливает программу при ошибке.
Свои примеры можно добавить в `main()`. Вводить данные с клавиатуры не нужно.
Все файлы сразу в одну программу собирать не надо: у каждого свой `main()`.
